# Shopping List

## Objective

Build an interactive shopping list application that allows users to add items, mark them as purchased, delete items, view total counts, and clear the list.

## Requirements

- Input field to add a new grocery/shopping item.
- Add item button and form submission on Enter.
- Display all added items in a list.
- Checkbox or click interaction to mark an item as purchased (strikethrough styling).
- Delete button for each individual item.
- Display total items and count of purchased items (e.g. "3 of 5 items purchased").
- "Clear All" button to empty the list.

## Concepts Practiced

- Array of item objects (`{ id, name, purchased }`)
- DOM creation and manipulation
- Event handling and state updates
- Array methods (`filter()`, `push()`, `findIndex()`)
- Basic CRUD operations

## Bonus Challenges

- Add quantity selector (e.g. "2x Milk").
- Persist shopping list items in `localStorage`.

## Restrictions

Use only HTML, CSS and Vanilla JavaScript.

Do not use frameworks or libraries.

## How to Run

Open `index.html` in a browser.
