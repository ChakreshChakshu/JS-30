# Counter App

## Objective

Build a simple counter application that allows users to increase, decrease, and reset a numeric value displayed on screen.

## Requirements

- Display the current count starting at 0.
- Provide an "Increment" button that increases the count by 1.
- Provide a "Decrement" button that decreases the count by 1.
- Provide a "Reset" button that sets the count back to 0.
- Change the color of the count display based on its value (e.g., green for positive, red for negative, neutral for zero).

## Concepts Practiced

- Variables and state management
- DOM selection using `document.getElementById` or `document.querySelector`
- Modifying DOM content using `textContent`
- Event listeners using `addEventListener`
- Functions and conditional statements

## Bonus Challenges

- Add an input to customize the step size (e.g., increment by 5 or 10).
- Add keyboard shortcuts (ArrowUp for increment, ArrowDown for decrement, 'r' for reset).
- Prevent the counter from going below a minimum value or above a maximum value.

## Restrictions

Use only HTML, CSS and Vanilla JavaScript.

Do not use frameworks or libraries.

## How to Run

Open `index.html` in a browser.
