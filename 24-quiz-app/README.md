# Quiz App

## Objective

Build an interactive multiple-choice quiz application containing at least 10 web development questions, immediate choice evaluation, progress tracking, and final score summary.

## Requirements

- Array of at least 10 question objects with choices and correct answer index.
- Display current question and choice buttons.
- Select choice to immediately show visual feedback (correct in green, wrong in red).
- "Next Question" button disabled until an answer is selected.
- Progress bar and question counter (e.g. "Question 3 of 10").
- Final score screen displaying percentage and performance rating.
- "Restart Quiz" button to reset and play again.

## Concepts Practiced

- Array of complex objects (`questions`)
- State management (`currentIndex`, `score`, `answered`)
- Event handling and dynamic DOM reconstruction
- Conditional class styling

## Bonus Challenges

- Add a per-question countdown timer (e.g. 15 seconds per question).
- Shuffle questions and choices on each quiz restart.

## Restrictions

Use only HTML, CSS and Vanilla JavaScript.

Do not use frameworks or libraries.

## How to Run

Open `index.html` in a browser.
