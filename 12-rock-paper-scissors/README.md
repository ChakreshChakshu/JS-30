# Rock Paper Scissors

## Objective

Build a classic Rock, Paper, Scissors game where the player competes against a randomized computer opponent with running score tracking.

## Requirements

- Buttons allowing the user to select Rock, Paper, or Scissors.
- Computer randomly picks one of the three options.
- Determine winner based on game rules:
  - Rock beats Scissors
  - Scissors beats Paper
  - Paper beats Rock
  - Same choice results in a Draw
- Display both choices and round outcome clearly.
- Maintain running score: Player wins, Computer wins, and Draws.
- Provide a button to reset scores.

## Concepts Practiced

- Array of choices: `['rock', 'paper', 'scissors']`
- Random selection with `Math.random()`
- Game rule logic and win condition determination
- State management across multiple rounds
- Dynamic UI feedback and DOM updates

## Bonus Challenges

- Add a "Best of 5" tournament mode with a championship trophy modal.
- Add animation shake effects before revealing the computer's choice.

## Restrictions

Use only HTML, CSS and Vanilla JavaScript.

Do not use frameworks or libraries.

## How to Run

Open `index.html` in a browser.
