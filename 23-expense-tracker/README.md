# Expense Tracker

## Objective

Build a budget and personal finance expense tracker that calculates net balance, total income, and total expenses using `Array.prototype.reduce()`, persisted via `localStorage`.

## Requirements

- Add transactions with text description, amount, and type (income or expense).
- Calculate and display:
  - Current Net Balance
  - Total Income
  - Total Expenses
- Use `reduce()` to compute aggregate financial totals.
- Render history of transactions with positive (green) and negative (red) indicators.
- Provide a delete button for each transaction.
- Persist transactions in `localStorage`.

## Concepts Practiced

- `Array.prototype.reduce()` for data aggregation
- Number formatting and arithmetic
- `localStorage` read and write persistence
- Dynamic DOM insertion and deletion

## Bonus Challenges

- Add category tags (Food, Rent, Salary, Entertainment).
- Add confirmation prompt before deleting transactions.

## Restrictions

Use only HTML, CSS and Vanilla JavaScript.

Do not use frameworks or libraries.

## How to Run

Open `index.html` in a browser.
